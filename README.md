# 単語カード帳

中高生向けのフラッシュカード＆小テストアプリです（埼玉県公立入試対策：数学・理科・社会・英語の一問一答と数学の計算問題、計271問入り）。

- 公開URL: https://ooooo623.github.io/1126/ — **配布したQRコードから開いたときだけ使えます**
- 先生向けの説明（成績の集め方・AI分析の指示文・問題の更新方法）: [先生用ガイド.md](先生用ガイド.md)

## 特長
- 問題セットを作って、カードで覚えて、小テスト（4択／記述）で確認
- 分析タブで単元ごとの正答率・苦手な問題・アドバイスを表示。「成績をコピー」で先生に提出
- 問題データは暗号化済み。合言葉はQRコードのURLの中だけにあります
- 成績や自作の問題はブラウザ内（localStorage）にだけ保存。サーバーには送信しません

## ファイル
- `index.html` … アプリ本体（暗号化した問題データ入り）
- `build.py` … 問題データを暗号化して index.html に埋め込み、QRコードを作るスクリプト
- `private/` … 問題の元データ・合言葉・QRコード（**公開しない**。.gitignore 済み）
- `.nojekyll` … GitHub Pagesでそのまま配信するための空ファイル
