# 単語カード帳

中高生向けのフラッシュカード＆小テストアプリです。

- 公開URL: https://ooooo623.github.io/1126/
- QRコード: [qr.png](qr.png)（教室で配布・掲示できます）

## 特長
- 問題セットを作って、カードで覚えて、小テスト（4択／記述）で確認
- データはブラウザ内（localStorage）にだけ保存。サーバーには送信しません
- 端末やブラウザが変わるとデータは引き継がれません。「書き出し」でバックアップできます

## ファイル
- `index.html` … アプリ本体（このファイル1つで動きます）
- `qr.png` … 公開URLのQRコード
- `make_qr.py` … QRコードを作り直すスクリプト（`python3 make_qr.py <URL>`）
- `.nojekyll` … GitHub Pagesでそのまま配信するための空ファイル
